# Playwright Testing for Forge IDE

## Test Execution
- Run unit/integration tests: `npm test` or `node scripts/test.bat`.
- Run web integration: `node scripts/test-web-integration.bat`.
- Debug failed test assertions by inspecting snapshots and trace logs.
