# Git Operations & Repository Standards

## Workflow
1. Check repository status: `git status -s`.
2. Inspect branch differences: `git diff`.
3. Create feature branches: `git checkout -b <branch-name>`.
4. Write clean, descriptive commit messages adhering to conventional commit formatting.
