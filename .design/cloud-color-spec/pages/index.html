Cerulean Cloud

A soft sky-blue accent derived from the CocoIndex paper base (#fff8ea), shifted toward complementary blue to serve as a distinct “Idea” accent. Sits opposite terracotta on the color wheel, providing a cool, airy counterpoint to the warm CocoIndex palette.

Derivation
#fff8ea Paper → Shift hue +200°, reduce warmth → #8ecae6
Starting from CocoIndex paper (warm cream), the hue is rotated approximately 200° toward cerulean blue while preserving similar luminance. This creates a natural complementary relationship with the terracotta accent while maintaining the soft, luminous quality of the paper base.

CSS Implementation

/* Add to .forge-coco-shell in styles.css */
--forge-coco-cloud:       #8ecae6;
--forge-coco-cloud-light:  #c4dff0;
--forge-coco-cloud-soft:   rgba(142, 202, 230, 0.15);
Add these three lines inside the .forge-coco-shell rule block in src/vs/workbench/contrib/void/browser/react/src/styles.css (around line 228, after --forge-coco-accent-soft).
